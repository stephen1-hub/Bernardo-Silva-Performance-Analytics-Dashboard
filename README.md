# ⚽ Bernardo Silva Performance Analytics Dashboard

## Overview

This project is a football analytics scouting dashboard built with Python and Streamlit.

It analyzes the career performance of Bernardo Silva (2017/18 – 2025/26) using:

xG-based metrics
Creative output indicators
Per 90 performance measures
Season-by-season trend analysis
Expected vs actual efficiency modeling

The goal is to simulate a professional club performance review interface (Opta-style) for midfielder evaluation.

## Key Features

📈 Player performance overview (Goals, Assists, xG, xA, KP/90)
🎨 Creative output analysis (Key Passes per 90, xA per 90)
⚖️ Expected vs Actual performance comparison (xG vs Goals, xA vs Assists)
📊 Season-by-season trend visualization
⏱️ Minutes played vs productivity analysis
🧠 Scouting insight summary
🎛️ Interactive season filter with “Select All” option
🌐 Clean Streamlit-based dashboard interface

## Key Insights
Multiple performance peaks across different tactical phases
Strong alignment between expected metrics (xG/xA) and actual output
Creative resurgence observed in later seasons
Stable per-90 impact regardless of role changes
High adaptability across midfield systems
No clear long-term decline in underlying performance indicators

Profile fits a hybrid creative midfielder archetype:
Playmaker + Advanced Midfield Contributor
